# App image assets

The provided PNG files are used by the app with these names:

- `ooca-logo.png` - OOCA wordmark used in the shared header on every view.
- `mooca.png` - Home and thank-you views.
- `mooca-create.png` - Create view.
- `mooca-read.png` - Read view.
- `envelope.png` - Opening-letter modal.

The envelope seal keeps its built-in illustration. Missing mascot images fall back to the built-in SVG. Letter drawings are user-created content and are not stored here.
